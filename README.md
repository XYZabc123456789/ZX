# Note for building:
This compiler requires LLVM 22.1 installed. Get the required installation from <a href="https://github.com/llvm/llvm-project/releases#release-llvmorg-22.1.8">here</a>. Select clang+llvm-22.1.8-x86_64-pc-windows-msvc.tar.xz from assets option. Extract the files & save it to a folder. The file path should not have any spaces. Add path\to\installation\bin to your PATH env var.
